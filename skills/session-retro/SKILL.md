# Session Retro

세션을 마무리하며 시스템 세팅(CLAUDE.md, 스킬, 설정)의 개선 포인트를 검토하고 적용한다.

## 왜 이 스킬이 필요한가

세션 중에 발견되는 개선 포인트는 그 순간이 아니면 잊혀진다. 에러를 우회했거나, 정보가 부족해서 질문했거나, 스킬이 기대와 다르게 동작했거나 — 이런 마찰들은 세션이 끝나면 기억에서 사라진다. 이 스킬은 세션의 흐름을 돌아보고 반복되는 마찰을 시스템 레벨에서 제거한다.

## 분석 대상

세션 대화 이력에서 다음 신호를 찾는다:

### 1. CLAUDE.md 개선
- 세션 중 사용자에게 **직접 물어봐야 했던 정보** (테스트 계정, 환경 설정, 선호 패턴 등)
- 문서에 없어서 **탐색으로 파악해야 했던 컨벤션**
- 새로 도입된 패턴이나 도구 (이번 세션에서 처음 사용한 라이브러리, API 등)

### 2. 스킬 버그/개선
- 스킬 실행 중 발생한 **에러나 우회** (잘못된 CLI 플래그, 누락된 단계 등)
- 스킬 간 **연계가 매끄럽지 않았던 지점** (수동 호출이 필요했던 자동화 가능 구간)
- 스킬이 **트리거되지 않아 수동으로 호출**한 경우

### 3. 새 스킬 제안
- 세션에서 **반복된 다단계 작업**이 패턴화 가능한 경우
- 기존 스킬이 커버하지 않는 **새로운 워크플로우**가 등장한 경우

### 4. 설정/권한 개선
- **권한 프롬프트가 반복**된 명령어 (allowlist 추가 대상)
- 환경 변수, 훅, 기타 `settings.json` 변경이 도움이 될 경우

## 워크플로우

### Step 1: 세션 분석

대화 이력을 처음부터 훑으며 위 4가지 카테고리에 해당하는 신호를 수집한다. 각 신호에 대해:
- **무엇이 문제였는가** (증상)
- **왜 발생했는가** (원인)
- **어떻게 해결할 수 있는가** (제안)
- **우선순위** — 🔴 버그/에러(동작이 깨짐) > 🟡 마찰(우회 필요) > 🟢 개선(있으면 좋음)

**다중 CLAUDE.md 대응**: 크로스 레포 워크스페이스에서는 변경 대상 CLAUDE.md를 정확히 특정한다. 프론트엔드 전용 컨벤션은 `frontend/CLAUDE.md`, 백엔드 전용은 `backend/CLAUDE.md`, 양쪽 공통 규칙은 루트 `CLAUDE.md`에 반영한다.

### Step 2: 개선 포인트 제시

발견한 포인트를 카테고리별로 정리하여 사용자에게 제시한다. 각 항목은 한 줄 요약 + 구체적 변경 내용을 포함한다.

제시 형식:

```
### 1. CLAUDE.md 개선 (N건)
| # | 항목 | 변경 내용 | 대상 파일 |
|---|------|----------|----------|

### 2. 스킬 버그/개선 (N건)
| # | 스킬명 | 문제 | 수정 내용 |
|---|--------|------|----------|

### 3. 새 스킬 제안 (N건)
| # | 스킬명 | 용도 |
|---|--------|------|

### 4. 설정/권한 (N건)
| # | 항목 | 변경 내용 |
|---|------|----------|
```

발견된 포인트가 없는 카테고리는 생략한다.

### Step 3: 선택적 적용

AskUserQuestion으로 어떤 항목을 적용할지 확인한다. 선택지:
- **모두 적용** — 전체 항목 일괄 적용
- **선택 적용** — 사용자에게 번호로 선택받기 (Other 입력으로 "1,2,4" 형태)
- **건너뛰기** — 적용하지 않음

항목이 많을 경우 AskUserQuestion의 옵션 수 제한(최대 4개)에 주의한다. 개별 항목을 옵션으로 나열하지 말고, 위 3가지 선택지만 제시한 뒤 "선택 적용" 시 번호를 받는 방식으로 처리한다.

승인된 항목을 즉시 적용한다:
- CLAUDE.md → Edit tool로 수정
- 스킬 → 해당 SKILL.md 수정
- 새 스킬 → `/skill-creator` 스킬 사용을 제안 (이 스킬에서 직접 생성하지 않음)
- 설정 → `update-config` 스킬 사용을 제안

### Step 4: 적용 결과 요약

```
## Session Retro 완료

| 카테고리 | 발견 | 적용 | 보류 |
|---------|------|------|------|
| CLAUDE.md | N건 | N건 | N건 |
| 스킬 개선 | N건 | N건 | N건 |
| 새 스킬 | N건 | - | N건 |
| 설정 | N건 | N건 | N건 |
```

## 주의사항

- 개선 포인트가 없으면 "이번 세션에서는 특별한 개선 포인트가 없습니다"로 짧게 마무리한다. 억지로 찾지 않는다.
- CLAUDE.md에 민감한 정보(프로덕션 비밀번호 등)를 추가하지 않는다. 테스트 계정 정도는 허용.
- 스킬 수정 시 기존 동작을 깨뜨리지 않도록 최소 변경 원칙을 따른다.
- 새 스킬 제안은 반복 패턴이 명확할 때만 한다. 일회성 작업은 스킬화하지 않는다.
